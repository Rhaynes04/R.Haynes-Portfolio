# Renthal Haynes — Portfolio

Static professional website focused on technology solutions delivery, ITSM / business process analysis, and project coordination.

Pages:
- `index.html` — homepage
- `agrilife.html` — Texas A&M AgriLife case study
- `workday.html` — Workday proof-of-concept case study
- `styles.css` and `script.js` — styling and navigation

## Publish with GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.

Expected published address: https://rhaynes04.github.io/R.Haynes-Portfolio/

## Resume file

The website references `assets/Renthal_Haynes_Resume.pdf`, which needs to be uploaded separately because it is a binary file. Review your contact details before publishing any resume on a public website.
